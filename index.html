About this ledger

Terra Motus is a live ledger of natural events on Earth, drawn from NASA's Earth Observatory Natural Event Tracker (EONET). Each time the page opens it asks EONET for the latest events in thirteen categories and keeps those observed in the past 30 days, newest first.

Each row gives the date of the latest observation, the category, the event's name and its coordinates. Click a row to open the source report for that event, and type in the search box to filter the ledger by name or category.

  • Categories: wildfires, severe storms, volcanoes, floods, earthquakes, landslides, drought, dust and haze, sea and lake ice, snow, temperature extremes, water color, and manmade events.
  • Source: NASA EONET v3, which curates events from NASA and partner agencies. Timing and positions are EONET's.
  • No account, no tracking; the page is a single HTML file by Curtis Hoffmann, source on GitHub.
